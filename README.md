### About me

I'm **Yanbo Bian (卞彦博)**, a third-year Computer Science and Technology undergraduate at **Beijing Jiaotong University**.<br>My research connects **reliable and efficient inference**, **multimodal learning**, and **resource-aware edge intelligence**. I develop methods, evaluate them under explicit protocols, and release code and experimental evidence so others can inspect and build on the work.

**Education:** 2024–2028 (expected) &nbsp;

<br clear="all" />

> **WSDM 2027 · Main Conference · First author**  
> My paper **SemAudit: Testing Semantic Reliance in Text-Augmented Forecasting over Irregular Event Streams** has been accepted to the WSDM 2027 main conference.

## Research focus

| Direction | Questions I work on |
| :--- | :--- |
| **Reliable, efficient inference** | When can repeated inference stop early while preserving prediction-set fidelity? How can uncertainty guide computation? |
| **Multimodal & deployment-time learning** | Does a model rely on aligned semantic content? How can online updates improve forecasts while controlling their revisions? |
| **Edge intelligence & reproducible evidence** | When should a system acquire an expensive sensing channel? How can experiments and software changes remain traceable? |

## Publications

**SemAudit: Testing Semantic Reliance in Text-Augmented Forecasting over Irregular Event Streams**  
Yanbo Bian · First author  
**[WSDM 2027](https://wsdm-conference.org/2027/), Main Conference — Accepted**  
Counterfactual semantic evaluation that preserves the observed event process, with a five-dataset, three-model-family audit and an independent positive control.

**Resource-Aware Safety-First Active Sensor Acquisition with Few-Shot Commissioning for Edge Fault Warning**  
Yanbo Bian · First author and co-corresponding author  
**Sensors 2026, 26(16), 5065 — Published** · [Paper](https://doi.org/10.3390/s26165065)  
Low-cost screening and on-demand sensor confirmation for resource-aware edge fault warning.

**Low-Cost Multi-Sensor Edge Intelligent Fault Diagnosis: A Framework Based on Lightweight Mamba and Cross-Modal Gating for Campus Electromechanical Equipment Health Monitoring**  
Yanbo Bian · First author  
**EIT 2026 — Accepted**  
Lightweight multimodal fault diagnosis, connected to an ESP32 acquisition and telemetry prototype.
